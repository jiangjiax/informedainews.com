ai-commit 使用 AI 自动生成 git 提交信息，支持 Bito Cli、ERNIE-Bot 和 OpenAI 等工具。用户选择提交类型——“feat”表示新功能，“fix”表示修复 bug——工具会生成详细的提交信息。例如，“chore”可能会生成“chore(ai-commit): 更新 tape 和 gif 资源。”工具在提交前会进行确认，确保准确性。

这种自动化节省了时间并保持了清晰度，使开发者在追求效率的同时不牺牲文档质量。

**解释：**
- **git 提交信息：** 在版本控制系统中添加到代码更改的描述。
- **AI 生成器：** 由人工智能驱动的创建内容的工具。
- **提交类型：** 用于组织更改的类别，如“feat”（新功能）或“fix”（bug 修复）。
